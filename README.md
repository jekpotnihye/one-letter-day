Entry for the make.fun competition
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36):
a program that writes exactly one letter, A–Z, standing for the word that
describes the day, to `/output/entry.txt` — one character and nothing else.

## Run

```sh
node main.ts
```

It creates `/output` if needed and writes the single-letter entry to
`/output/entry.txt` with no trailing newline.
